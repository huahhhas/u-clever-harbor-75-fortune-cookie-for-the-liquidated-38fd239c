One fortune-cookie line for a crypto trader who just got liquidated — oracular and slightly formal up front, then broken by a warm, rueful punchline:

> You lost the trade at 3am; the cookie, however, has never seen a trader so rich in almost.

## Run it

```sh
python3 main.py
```

Writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).
